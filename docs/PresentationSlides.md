# Code to Escape Presentation Slides

## 1. Title

Code to Escape: responsive web-based gamified programming learning.

## 2. Problem

Programming practice can lack feedback, progression, personalization, and sustained engagement.

## 3. Solution

A web platform combining coding challenges, escape-room progression, adaptive hints, duels, 3D scenes, social features, notifications, and learning analytics.

## 4. Architecture

React/Vite clients; Express/Socket.IO server; PostgreSQL/Prisma; Redis; Docker code runner; Groq; Firebase Cloud Messaging; React Three Fiber.

## 5. Core Workflow

Select a challenge, write code in Monaco, run in the isolated worker, receive diagnostics, earn progression, and review learning progress.

## 6. Adaptive Hints

Show learner profile context, hint type selection, fallback behavior, feedback, history, and privacy opt-out. Use a real seeded demo account; do not claim experimental effectiveness.

## 7. Real-Time and Social Features

Demonstrate a duel, synchronized progress, matchmaking, friends, messaging, and notification preferences.

## 8. Learning Measurement

Show assessments, sticky experiment assignment, opt-in telemetry, anonymized export, and admin analytics.

## 9. Evaluation Status

Present the preregistered methodology and clearly state whether participant data are available. Add findings only after approved analysis.

## 10. Limitations and Next Steps

Complete ethics review, recruitment, study analysis, load testing, accessibility audit, and production monitoring before making causal claims.
