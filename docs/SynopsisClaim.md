# Evidence Status for Synopsis Claims

No formal user study has been completed and no empirical results are currently available. The platform must not claim that it has demonstrated improved motivation, faster problem-solving, or better retention.

Until the protocol in `docs/EvaluationStudyProtocol.md` is completed, use:

> Code to Escape is designed to support motivation, problem-solving practice, and retention through gamified escape-room learning, AI hints, real-time duels, and progress measurement.

After a completed pilot with 30-60 participants, use `Pilot results suggest...` and report uncertainty, effect sizes, attrition, and limitations. Use `Results show...` only after the preregistered confirmatory analysis has sufficient power and supports the relevant claim.
